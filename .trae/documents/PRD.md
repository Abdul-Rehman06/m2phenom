## 1. Product Overview
M2 Phenom Public Landing Page
- A high-impact, public-facing website designed to introduce M2 Phenom software to new visitors.
- Showcases Dion ("Mr. Phenomenal Power"), the owner and visionary behind the software.
- Acts as a high-conversion funnel to drive users toward the client portal onboarding and registration.

## 2. Core Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| Public Visitor | None | View landing page, learn about the software, access auth links |

### 2.2 Feature Module
1. **Hero Section**: High-energy animated introduction, bold typography, strong value proposition.
2. **About the Owner (Dion)**: Dedicated section featuring Dion's image, his title ("Mr. Phenomenal Power"), and his mission.
3. **Features / Value Proposition**: Animated showcase of what M2 Phenom can do (credit repair, monitoring, automation).
4. **Call to Action (CTA)**: Prominent buttons directing users to "Get Started" (Onboarding/Registration) or "Client Login".

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| Public Landing | Hero | Dynamic background, animated headline, primary CTA. |
| Public Landing | Owner Profile | Image of Dion, bio text, floating elements, parallax effects. |
| Public Landing | Features | Staggered reveal of platform benefits using framer-motion. |
| Public Landing | Footer / CTA | Final push to convert visitors with links to auth routes. |

## 3. Core Process
1. Visitor lands on the root domain (`/` or public entry).
2. Experiences a highly animated, premium introduction to M2 Phenom.
3. Scrolls to discover the visionary (Dion) and the platform's power.
4. Clicks "Get Started" and is routed to the Client Registration/Onboarding flow.

## 4. User Interface Design
### 4.1 Design Style
- **Aesthetic**: Bold, maximalist, high-end "Silicon Valley" luxury. Not a simple template.
- **Colors**: Deep dark mode or striking light mode with brand-gradient accents (orange/primary). Since the user preferred light mode for the client portal, we will make this landing page incredibly sleek, possibly using a dark dramatic theme for the landing page to make it stand out as a premium marketing site, or a striking bright theme with heavy contrast. Let's aim for a high-contrast luxury feel (deep blacks, vibrant brand-gradient oranges/golds, and crisp whites).
- **Typography**: Oversized, bold, impactful headings. Clean, readable sans-serif for body.
- **Motion**: Heavy use of `framer-motion` for scroll-triggered reveals, parallax images, continuous floating animations, and magnetic buttons.

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| Public Landing | Hero | Large animated text, gradient meshes, animated CTA buttons. |
| Public Landing | Dion Profile | Masked image of Dion, floating badges, bold quotes. |

### 4.3 Responsiveness
Desktop-first, mobile-adaptive. Animations scale down gracefully on mobile devices.
